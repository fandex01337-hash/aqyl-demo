# Aqyl — ИИ-консультант для сайта компании

Чат-бот на сайте: подбирает удобрение под культуру и площадь, считает стоимость, отвечает по документам компании
(каталог, цены, доставка, оплата, FAQ) и собирает заявки. Языки: қазақша, русский, English. Можно писать или говорить голосом.

## Три версии сайта
Один и тот же сайт из папки `docs/` работает в трёх режимах — он сам понимает, где открыт.

| | Vercel | Ноутбук-сервер | GitHub Pages |
|---|---|---|---|
| Ответы | нейросеть Gemini | нейросеть Gemini | готовый сценарий (`docs/demo.js`) |
| Заявки | общая база Upstash Redis — со всех устройств | файл `заявки/заявки.txt` на ноутбуке | только в браузере клиента |
| Нужен ноутбук | нет | да, пока он включён | нет |

## Нейросеть
- Основная — **Google Gemini** (`gemini-flash-lite-latest`). Если модель перегружена или молчит дольше 25 секунд,
  сервер сам пробует запасные (`gemini-flash-latest`, `gemini-3.5-flash-lite`).
- Запасной вариант — **Claude**: если ключа Gemini нет, а ключ Claude есть, отвечает Claude.
- В системный промт подставляются `prompt.md` и все документы из `knowledge/`, поэтому Aqyl отвечает только
  по документам компании и указывает источник.
- Ответы приходят простым текстом: разметка Markdown (`**`, `#`, `*`) вырезается, списки идут через «•».
- Если в ответе есть блок `[ЗАЯВКА]{…}[/ЗАЯВКА]`, сервер вырезает его и сохраняет заявку.
- Нет ключа — сайт сам переходит в демо-режим по сценарию.

## Панель менеджера
Кнопка на сайте, открывается по паролю. Показывает все заявки и обновляется каждые 15 секунд.
- На Vercel пароль — переменная окружения `MANAGER_PASSWORD`.
- На ноутбуке — файл `manager-password.txt` (или та же переменная).
- На GitHub Pages пароль проверяет браузер по хешу SHA-256 в `docs/site.js` (сам пароль в коде не хранится).

Пароль, ключи и заявки в GitHub не попадают (см. `.gitignore`).

## Vercel (без ноутбука)
1. vercel.com → Add New → Project → импортировать этот репозиторий. Настройки сборки не трогать — всё в `vercel.json`.
2. Settings → Environment Variables:
   - `GEMINI_API_KEY` — ключ из Google AI Studio;
   - `MANAGER_PASSWORD` — пароль панели менеджера.
3. Storage → Upstash Redis → Connect к проекту. Vercel сам добавит `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. Deployments → ⋯ → Redeploy (новые переменные подхватываются только после передеплоя).

Дальше каждый push в `main` обновляет сайт на Vercel сам. Проверить настройки: `/api/config` показывает
`hasKey` (ключ нейросети), `leads` (база заявок) и `hasPassword` (пароль панели) — без самих значений.

## Ноутбук-сервер
```bash
node server.js
```
Сайт откроется на `http://localhost:3030`; адрес для телефонов в той же Wi-Fi сети печатается при запуске.
- Ключ нейросети — в файле `gemini-key.txt` (или `anthropic-key.txt` для Claude) рядом с `server.js`.
  Ключ и пароль читаются при каждом запросе — после замены перезапуск не нужен.
- Заявки — в папке `заявки/`: `заявки.txt` для человека (Блокнот, Word), `заявки.jsonl` для панели.
- Автозапуск при входе в Windows: ярлык в папке «Автозагрузка» → `start-server.vbs`.
  Он же запускает `tunnel.ps1` — публичную ссылку через Cloudflare. Ссылка меняется после перезагрузки,
  свежая всегда в файле «ССЫЛКА на сайт.txt».

## Презентация
`docs/presentation/index.html` — 10 слайдов про Aqyl, страница внутри сайта: `/presentation/`.
Листать стрелками ← →, пробелом, кликом или свайпом; F — во весь экран; `#7` в адресе открывает 7-й слайд.
На последнем слайде QR-код ведёт на https://aqyl-demo.vercel.app.

## Структура
- `docs/` — сайт: `index.html`, `site.js` (чат, панель менеджера), `demo.js` (демо-движок), `data.js`, `style.css`
- `docs/presentation/` — презентация
- `prompt.md` — системный промт Aqyl
- `knowledge/` — база знаний компании (демо-данные): каталог, доставка, инструкции
- `lib/ai.js` — общая логика нейросети (Gemini / Claude) для Vercel и ноутбука
- `lib/leads-store.js` — заявки в Upstash Redis (Vercel)
- `api/` — функции Vercel: `chat`, `config`, `lead`, `leads`, `leads/clear`
- `server.js` — сервер ноутбука, заявки в папку `заявки/`
- `vercel.json` — настройки Vercel

## Своя компания
Aqyl не привязан к удобрениям: замените документы в `knowledge/`, название компании и контакты
(переменные `COMPANY_NAME`, `MANAGER_CONTACTS`) — и получится консультант для другого бизнеса.
