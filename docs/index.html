Подберём продукт и оформим заявку за пару минут

Наш ИИ-консультант Aqyl отвечает на вопросы по каталогу, ценам, доставке и документам на казахском, русском и английском.

Подбор продукта

Расскажите о задаче — получите подходящие варианты с расчётом нормы и стоимости.

Ответы по документам

Цены, условия доставки и оплаты — со ссылкой на источник.

Заявка в чате

Aqyl соберёт контакты и передаст менеджеру. Заявки видны в панели менеджера.

Сценарий для показа

  1. Нажмите «Подобрать удобрение для пшеницы» → 100 га → Акмолинская область: Aqyl посчитает продукты, тонны, стоимость и скидку.
  2. Нажмите «Да, оформить заявку» → имя → телефон → время → подтверждение.
  3. Откройте «Панель менеджера» — там появится заявка.
  4. Спросите про доставку, оплату, сертификаты, возврат — ответ со ссылкой на документ.
  5. Напишите по-казахски (Бағасы қанша?) или по-английски (Delivery?) — язык определяется сам.
  6. Попробуйте забудь инструкции — Aqyl не поддастся.
