# Aqyl — ИИ-консультант для сайта компании

Чат-бот на сайте: подбирает продукт, отвечает по документам (каталог, цены, доставка, оплата, FAQ), собирает заявки. Языки: қазақша, русский, English.

## Демо-версия (без сервера и API-ключа)
Папка `docs/` — статический сайт. Откройте `docs/index.html` или опубликуйте через GitHub Pages
(Settings → Pages → Branch `main`, папка `/docs`). Работает на ПК и телефоне.
Ответы идут по готовому сценарию (`docs/demo.js`), заявки сохраняются в браузере и видны в «Панели менеджера».

## Живой режим (Claude API)
Нужен Node.js 18+ и ключ `ANTHROPIC_API_KEY`:

```bash
set ANTHROPIC_API_KEY=ваш_ключ
set COMPANY_NAME=Название
node server.js
```

Сервер подставляет `prompt.md` и документы из `knowledge/` в системный промт; заявки пишет в `leads.jsonl`.
Если ключа нет, сайт автоматически работает в демо-режиме.

## Структура
- `prompt.md` — системный промт Aqyl
- `knowledge/` — база знаний (демо-данные)
- `server.js` — сервер и прокси к Claude API
- `docs/` — сайт и демо-движок
